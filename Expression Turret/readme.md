# Arduino Robotic Face Project

## Coming Soon

This project is currently in the planning and development stage.

The goal is to create an interactive robotic face using an Arduino Nano, Adafruit QT Py SAMD21, 5×5 NeoPixel LED matrix, and a servo-controlled pan-tilt mechanism.

### Planned Features
- Programmable LED facial expressions
- Horizontal and vertical servo movement
- Coordinated movement and LED animations
- User-controlled commands through a computer interface

### Project Status
**Status:** Planning / Awaiting Hardware Assembly

Documentation, Arduino sketches, wiring diagrams, and testing results will be added as development progresses.

# Arduino QT Py + NeoPixel 5×5 Grid Project

## Coming Soon

This project will explore controlling a 5×5 RGB LED matrix using an Adafruit QT Py SAMD21 development board.

### Planned Features
- Control LED colors using Serial Monitor commands
- Support for predefined colors, RGB values, and HEX color codes
- Adjustable LED brightness
- Custom lighting patterns and animations

### Hardware
- Adafruit QT Py SAMD21 with STEMMA QT
- Adafruit 5×5 NeoPixel Grid BFF Add-On
- USB data cable

### Project Status
**Status:** Planning / Development

Arduino sketches, setup instructions, wiring information, and testing results will be added as the project progresses.
